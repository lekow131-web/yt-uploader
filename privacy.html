Privacy policy

Last updated: 24 November 2026

yt-uploader ("the app") is a private tool used only by its owner to manage the owner's own YouTube channels through the YouTube Data API v3. It uses YouTube API Services. By using the app you agree to the YouTube Terms of Service. The Google Privacy Policy also applies.

What data the app accesses

  • With the owner's permission (Google OAuth), the app accesses the owner's own YouTube channels: channel name and ID, the list of the owner's own uploads, and the videos, thumbnails, captions and playlists the owner publishes.
  • The app does not access, collect or store data of any other user. It does not read viewer data, comments, analytics or personal information of third parties.

How the data is used and stored

  • Data is used only to publish and update the owner's own videos.
  • The OAuth access token is stored only on the owner's own computer. Nothing is sent to any server other than Google's.
  • No data is sold, shared with third parties, or used for advertising.

How to revoke access

Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. Deleting the token file on the owner's computer also removes all stored access.
